# Shad - Private Messaging for Couples

A modern, secure, and romantic messaging app designed exclusively for couples.

## Features

- **One-to-one private messaging** with real-time chat
- **End-to-end encryption** for all messages, voice, and video calls
- **Media support**: text, images, videos, voice notes, GIFs, stickers, emojis
- **High-quality audio and video calling**
- **Message reactions and reply system**
- **Online/offline and typing indicators**

## Privacy & Security

- Strong end-to-end encryption
- App lock with PIN, fingerprint, or face unlock
- Screenshot detection and alert system
- Secret chat mode with self-destructing messages
- Private media vault for photos and videos

## Couple Features

- "Love Timeline" to save memories, important chats, and milestones
- Anniversary reminders and special day notifications
- Daily questions or bonding prompts for couples
- Shared music listening experience
- Custom nicknames for each other
- Mood-based chat themes (romantic, dark love, aesthetic)

## Architecture

- **Web App**: React with TypeScript, Vite
- **Mobile App**: React Native with Expo
- **Backend**: Node.js with Express and Socket.io
- **Database**: Firebase Firestore for real-time data
- **Authentication**: Firebase Auth
- **Encryption**: AES encryption using crypto-js

## Setup

1. Clone or set up the project.
2. For web: `cd web && npm install && npm run dev`
3. For mobile: `cd mobile && npm install && npm run web` (or android/ios)
4. For backend: `cd backend && npm install && npm run dev`
5. Set up Firebase project and add serviceAccountKey.json to backend.
