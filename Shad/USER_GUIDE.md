# 🎯 How to Use Shad - User Guide

## Getting Started

### Step 1: Launch the Application
```bash
# Terminal 1 - Start Backend
cd c:\Users\ELCOT\Shad\backend
node server.js

# Terminal 2 - Start Web App
cd c:\Users\ELCOT\Shad\web
npm run dev

# Open Browser
http://localhost:5174
```

## 👤 User Registration

### Creating Your Account (First Time)

1. **Click "Sign Up"** on the login screen
2. **Enter Your Details:**
   - Full Name: Your name
   - Email: Your email address
   - Password: Strong password (8+ characters)
3. **Click "Sign Up" Button**
4. **Success!** You'll be logged in automatically

**Note:** Your account is encrypted and stored securely on Firebase

## 🔗 Connecting with Your Partner

### First Time Connection

1. **View Your User ID:**
   - Dashboard → 💬 Chat tab
   - Scroll down to "Share Your ID"
   - Click 📋 Copy button
   - Your ID is copied to clipboard

2. **Share with Partner:**
   - Send your copied User ID to your partner
   - Ask for their User ID in return

3. **Connect with Partner:**
   - Ensure you have their:
     - Email address
     - User ID
   - Still on Dashboard → 💬 Chat tab
   - Click "🔗 Connect with Partner"
   - Enter Partner's Email
   - Enter Partner's User ID
   - Click "Connect" button

4. **Success!**
   - Dashboard shows "💕 Connected with [Email]"
   - Now you can start chatting!

---

## 💬 Sending Your First Message

### Open the Chat

1. **From Dashboard:**
   - Click 💬 Chat tab
   - Click "📱 Open Chat" button
   - Chat interface loads

### Send a Message

1. **Type Your Message:**
   - Click in the message input field
   - Type your message
   
2. **Send:**
   - Click "Send" button OR
   - Press Enter key

3. **What Happens:**
   - ✅ Message is encrypted
   - ✅ Sent to partner instantly
   - ✅ Shows as a pink bubble on your screen
   - ✅ Partner receives it decrypted
   - ✅ Appears as a gray bubble on their screen

### Features During Chat

- ⏱️ **Timestamps** - See when each message was sent
- ✍️ **Typing Indicator** - See when partner is typing
- 💬 **Real-time** - Messages appear instantly
- 🔐 **Encrypted** - All messages are encrypted

## 🆘 Troubleshooting

### "Cannot connect with partner"
- ✅ Verify partner's email spelling
- ✅ Verify partner's User ID is correct
- ✅ Partner must have account created
- ✅ Both apps must be running

### "Messages not sending"
- ✅ Check backend is running (port 3001)
- ✅ Check internet connection
- ✅ Refresh the page
- ✅ Check browser console for errors

### "Can't see typing indicator"
- ✅ Partner must have chat open
- ✅ Partner must be actively typing
- ✅ Check if partner is connected

### "Forgot password"
- ✅ Click "Cannot log in?" on login screen
- ✅ Use email to reset password
- ✅ Firebase will send reset link
